## 4. 潜在 Bug

- ISSUE-012（P3）：并发加购同 SKU 偶发唯一约束 409 而非累加。
- ISSUE-013（P3）：图片上传未校验文件魔数（扩展名/类型白名单已覆盖主要风险）。
- ISSUE-014（P3）：前后端邮箱校验规则不完全一致。
- ISSUE-015（P3）：Redis 数据丢失后 epoch 回退 0，短时旧 Access Token 可能复活（TTL 15 分钟）。
- ISSUE-016（P3）：禁用账号已登录会话提示文案为「登录已过期」而非「账号已被禁用」。
- ISSUE-007/008/009/010/018（P3）：限流计数与覆盖面、改密提交非原子、README 未说明 npm 源覆盖、测试依赖进镜像、本地开发默认口令。

## 5. 安全问题

- Git 仓库（含历史）无 .env/真实密码/JWT Secret/Token/密钥/构建产物；镜像内无 .env；`.gitignore` 全覆盖。
- JWT/Refresh/RBAC/Admin/用户状态/登录限流经静态与运行验证；无认证绕过、权限绕过、敏感信息泄露、硬编码真实 Secret。
- 登录限流 IP 伪造（ISSUE-011）已修复：优先 `X-Real-IP`，其次 XFF 末值。
- 既有设计说明：Token 存 localStorage（后续 httpOnly Cookie 优化项，非本次新增问题）；后端 8000 端口直接暴露（建议生产仅经 nginx，文档已说明）。
